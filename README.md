# 📊 Revenue-Focused Customer Churn Intelligence

> A consulting-grade churn risk diagnostic built on the IBM Telco dataset — combining ML modelling, revenue quantification, and an interactive Streamlit dashboard for executive decision-making.

---

## 📌 Overview

This project goes beyond academic churn modelling. It is designed to answer the questions a SaaS founder or revenue leader actually cares about:

- **Which customers are most likely to churn — and how much ARR is at risk?**
- **What are the strongest behavioural drivers of churn?**
- **If we run a targeted retention campaign, what is the expected ROI?**

The output is a fully-scored customer risk register, a PDF executive report, and a live interactive dashboard.

## 🔬 Notebook Walkthrough (`churn_analysis.ipynb`)

The notebook is structured in 9 sequential steps:

| Step | Title | What It Does |
|------|-------|--------------|
| 1 | Data Understanding & Quality | Load IBM Telco data, assess quality, compute foundational business metrics |
| 2 | Feature Engineering | Build tenure lifecycle flags, service engagement proxies, revenue indicators, and risk signals |
| 3 | Cohort & Retention Analysis | Survival/retention curves, contract cohort comparisons, SaaS retention benchmarks |
| 4 | Churn Risk Modelling | Train Logistic Regression, Decision Tree, and Random Forest with 5-fold cross-validation; select champion model by ROC-AUC |
| 5 | Full-Dataset Scoring | Score every customer with churn probability; assign High / Medium / Low risk tiers |
| 6 | Revenue at Risk Estimation | Compute MRR and ARR at risk per customer; identify the top 20% of accounts driving ~80% of risk |
| 7 | Intervention Simulation | Simulate ARR saved under 10%, 15%, and 20% churn probability reductions; calculate net ROI |
| 8 | Executive Report (PDF) | Auto-generate a 10-chart PDF report with business narrative using ReportLab |
| 9 | **Save Artefacts** | Export `test_features.csv`, `test_labels.csv`, `champion_model.pkl`, `feature_names.json` for the dashboard |

### Dataset

The project uses the publicly available **IBM Telco Customer Churn** dataset (~7,000 customers, 21 features including demographics, services subscribed, contract type, billing, and churn label).

---

## 🤖 Modelling Approach

Three models were trained and evaluated using 5-fold stratified cross-validation:

| Model | CV ROC-AUC | Notes |
|-------|-----------|-------|
| Logistic Regression | ✅ Champion | Interpretable coefficients; highest AUC |
| Decision Tree | — | Grid-searched depth/leaf parameters |
| Random Forest | — | Randomised search over 30 combinations |

The champion model (Logistic Regression) is wrapped in a `sklearn.Pipeline` with `StandardScaler` before saving, so the dashboard receives raw features and calls `predict_proba()` without any separate scaling step.

## 🖥️ Interactive Dashboard (`dashboard.py`)

A 4-tab Streamlit app for exploring model outputs in real time.

### Tabs

| Tab | What You Get |
|-----|-------------|
| **📊 Risk Overview** | KPI strip (customers scored, high-risk count, expected ARR loss, portfolio churn rate), risk tier donut, churn probability histogram, Top-N at-risk accounts table with CSV download |
| **💡 Intervention Simulator** | Scenario comparison table (Baseline + 10/15/20% effectiveness), grouped bar and dual-axis line charts, executive narrative with dynamic ROI calculation |
| **🔎 Churn Driver Explorer** | Select any feature; scatter plot of churn probability vs driver value (size = ARR at risk); quartile impact stats; top-20 filtered customer list with download |
| **📈 Model Performance** | Confusion matrix, ROC curve (with AUC), Precision-Recall curve, styled classification report |

### Sidebar Controls

- **High Risk Threshold** — adjusts which customers are flagged High vs Medium (0.50–0.90)
- **Show Top N At-Risk Accounts** — controls the size of the at-risk table
- **Intervention Effectiveness** — drives the ROI simulation (5%–30%)
- **Campaign Cost Assumption** — % of ARR saved assumed as campaign spend (10%–30%)
- **Churn Driver** — feature to explore in the Driver Explorer tab

## ⚙️ Setup & Running

### 1. Clone or download the repository

```bash
git clone https://github.com/your-username/churn_prediction_IBM.git
cd churn_prediction_IBM
```

### 2. Create a virtual environment (recommended)

```bash
python -m venv venv

# Windows
venv\Scripts\activate

# macOS / Linux
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the notebook to generate artefacts

Open `churn_analysis.ipynb` in Jupyter or VS Code and run all cells top to bottom.  
The final cell (Step 9) saves:

```
champion_model.pkl
test_features.csv
test_labels.csv
feature_names.json
```

### 5. Launch the dashboard

```bash
streamlit run dashboard.py
```

The app will open at `http://localhost:8501`. Click **🔍 Run Churn Analysis** in the sidebar to score customers and populate all tabs.

## 💡 Business Insights (Summary)

1. **Month-to-month contracts** drive the highest churn rate — switching incentives have the largest lever effect
2. **Tenure < 12 months** is the highest-risk lifecycle stage; early engagement programmes yield the best payback
3. **Customers without tech support or online security** churn at significantly higher rates — upsell opportunity and risk signal simultaneously
4. The **top 20% of at-risk customers by ARR** account for the majority of projected revenue loss
5. A **15% reduction** in churn probability across high-risk accounts yields a positive ROI even at a 20% campaign cost assumption
